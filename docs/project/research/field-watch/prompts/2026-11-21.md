### FW-20261121-1: Name Liquid's d1.2 models and mark d1 deprecated
Priority: P1. Size: S. Scope: vendor.
Depends on: none
Why: Liquid deprecated `d1`, `d1.1` and `d1-ultra` on 2026-11-16, and judgment's guide, plugin reference and `mise run live:liquid` still tell users to name `d1`.

Say that Liquid refuses zstd-compressed bodies, so the `zstd` feature must stay off for Liquid. Say that d1.2's extra answer types (`text`, `number`, `date`, `spans`, `box`/`boxes`, multi-select `choice`) are Liquid's extensions, which the crate neither sends nor reads. Update the doc comment of the `Liquid` profile in `tests/live.rs` without changing what it asserts. In `docs/project/verification/liquid.md`, say that the recorded run was against `d1` and `d1-ultra` and that no run against d1.2 is recorded. Update the Liquid row in `docs/project/research/compatible-servers-and-models.md` and the method table in `docs/project/verification/method.md`. Regenerate the llms files with the repository's script. Add a CHANGELOG entry under [Unreleased]. Do not run the live tests: they need the maintainer's key.
Spec: https://docs.liquid.ai/lfm/models/d1.md
Facts to re-verify:

- `d1:latest` and `d1-ultra:latest` "always point to the newest model of their family"; up to 128 questions; a 4.5 MB request body: https://docs.liquid.ai/api/reference/decision-models/make-decisions.md

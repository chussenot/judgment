# Check the .jud schemas against the types

**You will** generate the JSON Schema of the `.jud` types that are the file's own shape, and use it to keep a tool's schema in step with them. **Prerequisites:** the [`.jud` format](../reference/jud-format.md), and `judgment` with the `schema` feature (`schema` implies `jud`).

The published schemas, `schemas/jud/*.schema.json`, are written by hand and are the specification: they say what serde cannot derive, such as an `apiVersion` that decides whether `metadata.minor` is required, name patterns and the shape of a question. The `schema` feature adds the other direction, the schema the Rust types themselves have:

```rust
use judgment::jud::schema::definitions;

let defs = definitions();
let gate = &defs["Gate"];
// A gate's fields, as the type has them.
assert!(gate["properties"].get("threshold").is_some());
assert!(gate["properties"].get("bands").is_some());
// A gate refuses what it does not know.
assert_eq!(gate["additionalProperties"], false);
```

`definitions()` returns one schema per type, by name: `Metadata`, `AssetSource`, `BoxEdges`, `Gate`, `Band`, `Tuning`, `Case`, `BoxLabel`, `FromTurn`, and the types those name (`Expect`, `LevelRef`). Rubric, Cases and Recording themselves are read through wire structs with rules in code, so they are not here.

## What holds them together

`tests/jud_schema.rs` compares each generated shape with the committed schema it belongs to: the same fields, the same required fields, and closed wherever the type refuses unknown fields. Add a field to `Gate` and not to `schemas/jud/rubric.schema.json`, and the test fails naming `Gate` and both field lists. A type that tolerates an unknown field (`BoxEdges` reads any four numbers and checks their range elsewhere) makes no claim, so the file's stricter schema is not a disagreement.

## What the generated schemas do not say

They carry no patterns, ranges or conditions that code checks (a name's characters, a probability's `0..=1`, which gate fields fit which primitive). Validate a document against the committed schemas for that, and with `jud check` for the rest. Replacing the committed schemas with generated ones was considered and left out: the rules above would have to be written again as schemars attributes, a second source of truth for a format other tools implement.

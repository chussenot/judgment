The documentation follows Diátaxis: Start holds the tutorials (install, a first decision from the command line, a first decision in Rust), Guides the tasks (a backend, a rubric, cases, recordings, thresholds, CI, the container, the plugin, the patterns), Reference the facts (the jud command generated from its own help, the configuration, the normative .jud format specification, the crate's features and modules, the container image, stability, the glossary), Concepts the why (System One, rubrics, cases and recordings, how judgment works), and Project what is about the repository (contributing, internals, releasing, what real servers did, research, decisions). The crate has been run against the hosted TypeSafe API (`jev-1.13.0`), Laya's open-weights server and Ollama; its retry behaviour on 408, 429 and 529 is verified against wiremock only.
